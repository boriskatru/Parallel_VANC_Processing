## Физическое объяснение (для научников)

### Что обрабатывает программа?

**STM (Scanning Tunneling Microscope)** измеряет **локальную плотность состояний (LDOS)** через туннельный ток при различных напряжениях смещения.

### Три канала данных:

| Канал | Физический смысл | Единицы | Диапазон |
|-------|-----------------|---------|----------|
| **V** | Напряжение смещения | мВ | ±2000 мВ |
| **A** | Туннельный ток | пА | 0-100000 пА |
| **N** | Шум туннельного тока | пА²/Гц | 0-100+ |

### Почему Forward и Backward?

STM часто использует **биполярное сканирование**:
- **Forward (V > 0)**: занятые состояния ниже уровня Ферми
- **Backward (V < 0)**: незанятые состояния выше уровня Ферми

Разделение позволяет анализировать асимметрию спектра = информация о взаимодействиях.

### Почему фазовые сдвиги?

Электроника STM имеет задержку (обычно 5-20 мкс). Фазовые сдвиги синхронизируют каналы, иначе в VANC появляются артефакты.

### Почему фильтрация по качеству?

На практике периодически происходят события:
- Кратковременный контакт острия с образцом
- Скачок туннельного тока (jump-to-contact)
- Электромагнитные помехи
- Виброускорение

Эти события портят одну-две VANC, но не влияют на среднюю. Фильтрация их удаляет.

### Почему усреднение улучшает сигнал?

Для случайного шума с нулевым средним:
```
SNR_output = √N × SNR_input
```
Где N — количество усредняемых VANC. При N=100 улучшение в ~10 раз!
