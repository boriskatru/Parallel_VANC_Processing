# 📊 КРАТКОЕ РЕЗЮМЕ: Программа обработки VANC туннельного микроскопа STM

## ⚡ Что делает программа?

Автоматизирует обработку **Вольт-Амперных Характеристик (VANC)** — спектрометрических измерений образца, полученных с помощью **Scanning Tunneling Microscope (STM)**.

### Входные данные:
- Три канала данных (напряжение V, ток A, шум N) в трех бинарных файлах
- Каждый файл содержит 4 млн отсчетов с частотой 333 кГц

### Выходные данные:
- Две усредненные и отфильтрованные VANC (Forward и Backward)
- Улучшенное соотношение сигнал/шум в 5-10 раз
- Удаленные артефакты и выбросы

---

## 🔬 Физический смысл

| Параметр | Значение | Смысл |
|----------|----------|-------|
| **V** | 0 - 2000 мВ | Напряжение смещения |
| **A** | пикоамперы (пА) | Туннельный ток = информация о плотности состояний |
| **N** | пА²/Гц | Шум туннельного тока = информация о динамике |
| **FW** | V↑ (растет) | Сканирование в прямом направлении |
| **BW** | V↓ (падает) | Сканирование в обратном направлении |

│ 5️⃣  Применение фазовых сдвигов (синхронизация каналов) │

│ 7️⃣  Фильтрация по качеству (удаление плохих VANC)      │

## 💾 Структура данных

```cpp
// Одна VANC:
vector<vector<float>> vac(3, vector<float>(200));
// vac[0][i] = напряжение в точке i
// vac[1][i] = ток в точке i
// vac[2][i] = шум в точке i

// Набор VANC (например, из одного файла):
vector<vector<vector<float>>> vancs(100, vector<vector<float>>(3, vector<float>(200)));
// 100 независимых VANC, каждая с 3 каналами и 200 точками
```

## 🔧 Основные функции

| Функция | Назначение | Физика |
|---------|-----------|--------|
| `process_vancs()` | **Главная функция** обработки | Полный конвейер |
| `decimate_vanc()` | Понижение разрешения 500→200 | Шумоподавление |
| `avrg_curve()` | Простое усреднение N VANC | Улучшение SNR |
| `avrg_interpl_curve()` | Умное усреднение с корр. смещений | Коррекция дрейфа |
| `mean_sq_deviation()` | Метрика качества VANC | Отклонение от эталона |
| `reject_bad_vancs()` | Удаление плохих VANC | Фильтрация выбросов |
| `interpolate()` | Линейная интерполяция | Пересчет на новую сетку |

## 📞 Поддержка

При возникновении проблем:

1. **Проверить параметры**: phase_shift_cur, phase_shift_n должны быть образец-зависимыми
2. **Проверить data**: убедиться, что V, A, N корректно прочитаны из файлов
3. **Проверить период**: period = 333333 / freq должен быть правильным
4. **Увеличить crit_dev**: если слишком много VANC отклоняется
5. **Прочитать логи**: смотреть количество удаленных VANC и отклонение FW/BW
