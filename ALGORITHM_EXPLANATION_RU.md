# Подробное описание программы обработки Вольт-Амперных Характеристик туннельного микроскопа STM

## Общее описание

Эта программа выполняет **параллельную автоматизированную обработку Шум-Вольт-Амперных Характеристик (VANC)**, полученных с помощью **Scanning Tunneling Microscope (STM)** — туннельного сканирующего микроскопа.

### Что такое STM и VANC?

**STM (Scanning Tunneling Microscope)** — это инструмент в нанотехнологии, который позволяет получить информацию о поверхности образца на атомном уровне. Основан на явлении туннелирования электронов через вакуум между острием микроскопа и образцом.

**VANC (Вольт-Амперная Характеристика)** — зависимость туннельного тока от напряжения смещения между острием и образцом. При каждом напряжении также регистрируется шум туннельного тока, что дает информацию о локальной плотности состояний (LDOS) образца.

### Структура данных

Каждое измерение регистрирует **три величины**:
- **V (Voltage)**: напряжение смещения между острием и образцом (В)
- **A (Amplitude/Current)**: туннельный ток через зазор (в 10 нА)
- **N (Noise)**: шум туннельного тока (сигнал детектора в В)

Эти три канала сохраняются в три отдельных бинарных файла: `VANC_ᴦV.bin`, `VANC_ᴦA.bin`, `VANC_ᴦN.bin`, где ᴦ — номер VANC.

## Алгоритм обработки

### Этап 0: Предварительная подготовка

1. **Задание параметров** (либо по умолчанию, либо через интерактивный ввод):
   - **start, stop**: номера первой и последней VANC для обработки
   - **p_num**: требуемое разрешение выходной VANC (количество точек, обычно 200-400)
   - **period**: количество отсчетов в одном полном цикле биполярной развертки напряжения (вычисляется из частоты)
   - **freq**: частота развертки напряжения (например, 111.111 Гц)
   - **phase_shift_cur, phase_shift_n**: фазовые сдвиги токового и шумового каналов (образец-зависимые)
   - **crit_dev**: критерий качества для отклонения плохих VANC

2. **Проверка наличия файлов** на диске и уточнение диапазона обработки.

### Этап 1: Чтение данных (параллельно для разных файлов)

Для каждого номера VANC программа параллельно (используя OpenMP с 4 потоками):

1. Открывает три файла (`VANC_ᴦV.bin`, `VANC_ᴦA.bin`, `VANC_ᴦN.bin`)
2. Читает содержимое в буферы типа `float` (размер буфера: 4,000,000 отсчетов)
3. Объединяет три канала в единую структуру `data[3][size]`:
   - `data[0][]` = напряжение
   - `data[1][]` = ток
   - `data[2][]` = шум

Размер считанного буфера (`size`) определяется количеством успешно прочитанных отсчетов.

### Этап 2: Разделение на биполярные периоды и определение фазы

Типичная развертка напряжений в STM имеет **треугольную волну**: напряжение растет от Vmin к Vmax, потом падает обратно к Vmin. Один такой цикл = 1 **период**.

#### Что здесь происходит:

1. **Разбиение на полные периоды**:
   ```
   Количество периодов = size / period
   ```
   Каждый период разбивается на два полупериода:
   - **Полупериод 1**: V меняется от Vmin к Vmax (или наоборот)- FW
   - **Полупериод 2**: V меняется от Vmax к Vmin (или наоборот)- BW

2. **Определение фазы первого периода**:
   - Программа усредняет несколько первых периодов (для снижения шума)
   - Находит позицию минимума напряжения (min_1pos) и максимума (max_1pos) в каждом периоде
   - Определяет: какой полупериод идет первым?
     - Если min_1pos < max_1pos → растущее напряжение идет первым (`fw_first = true`)
     - Если max_1pos < min_1pos → падающее напряжение идет первым (`fw_first = false`)

3. **Нахождение начала**:
   - Определяется точка "старта" (раньше всего появляется минимум или максимум)
   - Все последующие обработанные полупериоды начинаются от этой точки
   - Причина: отсев кривой с обрезанными данными



### Этап 3: Разделение на Forward (FW) и Backward (BW)

Используя знание о фазе и периоде, программа разбивает каждый цикл напряжения на две половины:

```
Если fw_first == true:
  ├─ offset_fw = start + 0
  └─ offset_bw = start + period/2

Если fw_first == false:
  ├─ offset_fw = start + period/2
  └─ offset_bw = start + 0
```

Для каждой половины программа:
1. Извлекает данные половинки периода (обычно 500~1500 точек на полупериод, в зависимости от частоты)
2. **Применяет фазовые сдвиги (для простоты на целое число точек)**:
   - `fw_tmp[1][k] = data[1][..+ k + phase_shift_cur]` ← сдвигает ток вперед на phase_shift_cur отсчетов
   - `fw_tmp[2][k] = data[2][..+ k + phase_shift_n]` ← сдвигает шум вперед на phase_shift_n отсчетов

   **Зачем?** Туннельный ток и шум могут иметь задержку относительно команды напряжения из-за электроники. Сдвиги синхронизируют каналы.

3. **Переворачивает обратное сканирование** (BW):
   - Обратное сканирование идет от Vmax к Vmin
   - Для прямого сравнения нужно "перевернуть" ось V
   - Используется `std::reverse()` для разворота всех трех каналов B
#### Физический смысл:

Чтобы проверить консистентность измерений и отсутсвие резонансов/наводок, важно иметь сравнение характеристик измеренных по нарастанию напряджения и по убыванию напряжения.
В случае отсутвия проблем с измерениями, эти две характеристики  должны совпадать (после коррекции полярности).

### Этап 4: Децимация (понижение разрешения)

Каждый полупериод исходных данных (500+ точек) преобразуется в **p_num точек** (например, 100).

#### Алгоритм децимации:

```
Размер блока = length / p_num = 500 / 100 ≈ 5 отсчетв

Для каждой из p_num точек выходной VANC:
  output[i] = average(input[i * step : (i+1) * step])
```

**Преимущества децимации:**
- **Снижение шума**: усреднение нескольких отсчетов уменьшает случайный шум
- **Сжатие данных**: 500 точек → 100 точек экономит память
- **Улучшение статистики**: каждая выходная точка представляет среднее многих входных точек

**Важно:** Децимируются все три канала (V, A, N) независимо.

### Этап 5: Построение эталонной VANC и фильтрация плохих данных

После обработки одного файла имеется набор VANC (каждый период дает одну пару FW/BW):

```
fw_vancs[0..VAC_cnt-1] — набор прямых VANC
bw_vancs[0..VAC_cnt-1] — набор обратных VANC
```

#### Фильтрация включает два прохода:

**Проход 1: Среднеквадратичное отклонение от средней**

1. Вычисляется эталонная (средняя) VANC:
   ```cpp
   avrg_fw = mean_of(fw_vancs[0], fw_vancs[1], ..., fw_vancs[n])
   avrg_bw = mean_of(bw_vancs[0], bw_vancs[1], ..., bw_vancs[n])
   ```

2. Для каждой VANC вычисляется метрика качества — **среднеквадратичное отклонение (MSD)**:
   ```
   MSD_i = mean((interpolate(vancs[i], avrg[0]) - avrg[1])²)
   ```
   Это мера того, насколько хорошо данная VANC соответствует эталонной VANC.

3. VANC с `MSD > crit_dev` **удаляются** (считаются плохими):
   - Высокий шум
   - Артефакты (резкие скачки контакта)
   - Помехи от электроники

**Проход 2: Пересчет эталонной на отфильтрованных данных**

После удаления плохих VANC эталонная VANC пересчитывается на оставшихся, "хороших" данных. Это дает более чистую эталонную VANC.
Затем 
#### Физический смысл фильтрации:

В реальных экспериментах STM случаются случайные события:
- Виброускорение пьезоэлектрического сканера
- Кратковременный контакт острия с образцом
- Электромагнитные помехи
- Дрейф туннельного тока

Эти события портят отдельные VANC, но не влияют на среднюю. Фильтрация их удаляет, оставляя только статистически значимые данные.

### Этап 6: Контроль качества

После фильтрации проверяется, осталось ли хотя бы несколько VANC:

```cpp
if (avrg_fw.size() == 0 || avrg_bw.size() == 0) {
    // ОШИБКА: все VANC отклонены! Возвращаем маркер EMPTY_VANC
    return (EMPTY_VANC, EMPTY_VANC)
}
```

Если все VANC отклонены — это указывает на серьезные проблемы с измерением (например, потеря контакта острия с образцом).

### Этап 7: Вычисление отклонения между FW и BW

```cpp
deviation_fw_bw = mean_sq_deviation(avrg_bw, avrg_fw)
```

Эта метрика показывает, насколько отличаются прямое и обратное сканирования. Небольшое отклонение (< 0.1) указывает на хорошую воспроизводимость. Большое отклонение может указывать на:
- Дрейф образца между FW и BW
- Нестабильность туннельного контакта
- Физические изменения образца

### Этап 8: Параллельная обработка всех файлов

Все описанные выше этапы (2-7) повторяются для каждого файла параллельно, используя **4 потока OpenMP**.

Результаты FW и BW VANC из каждого файла добавляются в общие накопители:
```cpp
fw_vancs.insert(fw_vancs.end(), VANCS.first);   // Добавить текущие FW VANC
bw_vancs.insert(bw_vancs.end(), VANCS.second);  // Добавить текущие BW VANC
```

### Этап 9: Финальное усреднение всех файлов

После обработки всех файлов имеется большой набор FW и BW VANC из разных мест образца.

1. **Интерполяция на равномерную сетку**:
   - Все VANC интерполируются на единую сетку напряжений
   - Используется алгоритм с перепроецированием на равномерную сетку с линейной аппрокисмауией

2. **Финальное усреднение**:
   ```cpp
   avrg_fw = mean_with_interpolation(fw_vancs, p_num)
   avrg_bw = mean_with_interpolation(bw_vancs, p_num)
   ```

3. **Финальная строгая фильтрация** (crit_dev/25):
   - Используется очень строгий критерий (crit_dev/25 вместо crit_dev)
   - Удаляются даже слегка отклоняющиеся VANC

### Этап 10: Сохранение результатов

Финальные усредненные VANC сохраняются в два файла:
- `VANC_FW_P{p_num}_S{time}.dat` — прямое сканирование
- `VANC_BW_P{p_num}_S{time}.dat` — обратное сканирование

**Формат файла** (три столбца, разделены пробелами):
```
V1 A1 N1
V2 A2 N2
V3 A3 N3
...
```

Где каждая строка — одна точка на оси напряжений.

## Ключевые алгоритмы

### 1. Усреднение (avrg_curve)

```
Входные данные: множество VANC (каждая с тремя каналами)
Для каждой точки k:
  avrg[0][k] = sum(vac[i][0][k]) / count
  avrg[1][k] = sum(vac[i][1][k]) / count
  avrg[2][k] = sum(vac[i][2][k]) / count
```

**Эффект**: снижение случайного шума в √N раз (где N — количество VANC).

### 2. Интерполяция (interpolate)

Линейная интерполяция между двумя ближайшими точками:
```
Если target находится между points[n] и points[n+1]:
  value = (target - points[n]) / (points[n+1] - points[n]) * 
          (values[n+1] - values[n]) + values[n]
```

Используется для пересчета данных на новую сетку напряжений.

### 3. Интерполяция с перепроецированием (avrg_interpl_curve)

Более сложный алгоритм, учитывающий, что разные VANC могут иметь разные "точки приложения":

```
1. Создать равномерную сетку: V_сетка[0], V_сетка[1], ..., V_сетка[p_num]
2. Для каждой точки каждой VANC:
   - Найти ближайшую точку в сетке
   - Добавить значение к этой ячейке сетки
   - Увеличить счетчик этой ячейки
3. Нормировать каждую ячейку по ее счетчику
```

**Преимущество**: более надёжное усреднение при наличии смещений между VANC.

### 4. Среднеквадратичное отклонение (mean_sq_deviation)

```
deviation = mean((interpolate(test_vanc, ref[0]) - ref[1])²)
```

Это мера того, насколько хорошо тестовая VANC соответствует эталонной VANC. Низкое значение (< 0.01) указывает на высокое качество.

## Параллелизм

Программа использует **OpenMP** для параллельной обработки разных файлов VANC:

```cpp
#pragma omp parallel for
for (int i = start; i < stop; i++) {
    // Обработка файла номер i
    // Может выполняться параллельно до 4 потоков
}
```

**Зачем?** Обработка одного файла (~1-10 сек) занимает время. Если процессор имеет 4 ядра, можно обрабатывать 4 файла одновременно, ускоряя общее время в ~4 раза.

**Ограничения параллелизма:**
- Операции чтения/записи на диск не распараллеливаются хорошо
- Синхронизация при добавлении результатов в общие вектора
- Возможны конфликты кэша при доступе к `fw_vancs` и `bw_vancs`

## Физическая интерпретация результатов

### Что показывает V (Voltage)?
Напряжение смещения между острием STM и образцом, обычно в диапазоне ±2 V.

### Что показывает A (Amplitude/Current)?
Туннельный ток через вакуумный зазор (в десятках нА). Экспоненциально зависит от расстояния острия до образца и от локальной плотности состояний (LDOS).

### Что показывает N (Noise)?
Флуктуации туннельного тока, вызванные:
- Температурой или неравновесным распределением носителей
- Зарядом носителй 

### Как интерпретировать результаты?

1. **Форма VANC** (график A vs V):
   - Крутой подъем = резкое возрастание LDOS (острая особенность в спектре)
   - Плавный подъем = размытая LDOS (широкая особенность)

2. **Отклонение FW от BW**:
   - Малое отклонение = образец стабилен, острие стабильно
   - Большое отклонение = наводки и/или нестабильность 

3. **Форма N (шум) vs V**:
   - F=1 в NIN контакте
   - F>1 в NIS\SIS контктах при малых баясах

| Проблема | Причина | Решение |
|----------|---------|---------|
| Все VANC отклонены | Потеря контакта острия | Перенастроить STM, повторить измерения |
| Большое отклонение FW/BW | Дрейф образца | Ждать стабилизации, повторить сканирование |
